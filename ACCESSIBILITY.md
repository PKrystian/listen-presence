# Accessibility

The popup is designed for keyboard navigation, visible focus, browser zoom, narrow
windows, and screen readers. Status is communicated with text and live updates, not color
alone. The sharing switch has an accessible label, and error messages use an alert region.

Report an accessibility barrier through the repository issue tracker. Include the browser,
assistive technology, affected control, expected result, and a description of the barrier.
Do not include passwords, track history, or other sensitive information in a public issue.
