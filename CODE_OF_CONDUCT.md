# Code of conduct

## Our standard

ListenPresence contributors are expected to keep project spaces respectful, focused, and
safe. Constructive disagreement is welcome. Harassment, discrimination, threats,
deliberate disruption, publication of private information, and sexualized attention are
not acceptable.

## Scope

This standard applies to issues, pull requests, discussions, reviews, and other spaces
managed by the project. It also applies when someone represents the project elsewhere.

## Enforcement

Report conduct concerns privately to the maintainer through a private GitHub channel. Do
not include sensitive details in a public issue. The maintainer may edit or remove
contributions, limit participation, or ban a participant when necessary.

## Attribution

This policy is informed by the Contributor Covenant 2.1 and adapted into concise project
wording.
