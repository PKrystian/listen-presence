# Support

ListenPresence is a free community project without guaranteed response times or service
levels.

Search existing issues before opening a new one. For a bug, include the browser and
version, operating system version, extension version, connector status, and reproducible
steps. Do not include cookies, passwords, Discord tokens, private URLs, or track history.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue. Accessibility
reports should include the assistive technology and affected control. Content or trademark
requests should follow [COPYRIGHT.md](COPYRIGHT.md).

The project and public source repository are maintained by Krystian Pińczak. Current
contact channels are available at https://github.com/PKrystian.
